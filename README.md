\# Student Performance Analyzer



A web-based Student Performance Analyzer built using Flask, Python, Pandas, HTML, CSS, and Chart.js.



\## Features



\- Add student marks

\- Calculate average marks automatically

\- Generate performance levels

\- Generate grades automatically

\- View all students

\- Search students by name, grade, or performance

\- Identify the top performer

\- Subject-wise performance analysis

\- Grade distribution charts

\- Performance distribution charts

\- Student average comparison

\- Download student performance data as CSV

\- Responsive dashboard interface



\## Technologies Used



\- Python

\- Flask

\- Pandas

\- HTML5

\- CSS3

\- JavaScript

\- Chart.js



\## Performance Criteria



\### Performance



\- Excellent: 85 and above

\- Good: 70 - 84

\- Average: 50 - 69

\- Needs Improvement: Below 50



\### Grades



\- A+: 90 and above

\- A: 80 - 89

\- B: 70 - 79

\- C: 60 - 69

\- D: 50 - 59

\- F: Below 50
