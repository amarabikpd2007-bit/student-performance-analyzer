📚 About the Project

Student Performance Analyzer is a web-based application designed to analyze and track student academic performance. It allows users to enter student marks, calculate averages, assign grades, identify performance levels and visualize academic data.

📊 Performance Analysis

Calculate student averages and classify performance as Excellent, Good, Average or Needs Improvement.

🏆 Top Performer

Automatically identify the student with the highest average marks.

📈 Data Analytics

View subject averages, grade distribution, performance distribution and student comparisons.

🛠 Technologies Used

Python Flask Pandas HTML CSS JavaScript Chart.js

🎯 Project Objective

The main objective of this project is to provide a simple and professional dashboard for managing student performance data and understanding academic trends through data analysis and visualization.
